# Omarchy Tetris

A single-file HTML Tetris game — no build step, no dependencies. Open `index.html` in any browser and play.

**Live:** [https://ulfmoby.github.io/omarchy-tetris/](https://ulfmoby.github.io/omarchy-tetris/)

---

## Features

- Full 10×20 board, all 7 standard pieces (I, O, T, S, Z, J, L)
- **Ghost piece** — shows where your piece will land
- **Next-piece preview**
- Score, lines cleared, and levels that speed up as you play
- Highscore system: best score persisted in localStorage, live "Best" display, and a "NEW BEST!" badge on game over
- Pause, restart, and a clean dark frozed-glass look
- **Sound effects** — distinct tones for 1/2/3/4-line clears, level-up chime, game-over jingle, lock tick (all generated with Web Audio API, no audio files)
- **Level-up screen flash** and floating text announcements
- **Mobile-ready** — touch buttons + swipe support (swipe left/right to move, swipe down to hard drop, swipe up to rotate)
- Works offline

---

## Controls

| Key | Action |
|-----|--------|
| ← / → | Move left / right |
| ↓ | Soft drop |
| ↑ | Rotate |
| Space | Hard drop |
| P | Pause / resume |
| M | Mute / unmute |

**Mobile:** On-screen touch buttons and swipe gestures on the board.
